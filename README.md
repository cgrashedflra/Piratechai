# 🏴‍☠️ Pirate Chai

### Find the right mentor. Learn your way.

Pirate Chai is a modern **ed-tech marketplace concept** designed to connect students with educators for personalized **1-to-1 tutoring and live batch classes**.

This repository contains the **frontend prototype** of the platform, built to explore the product experience, user flows, interface, and interaction patterns before implementing the full backend infrastructure.

🔗 **Live Demo:** [pirate-chai.ai.studio](https://pirate-chai.ai.studio)
💻 **Repository:** [github.com/cgrashedflra/Piratechai](https://github.com/cgrashedflra/Piratechai)

---

## ✨ What is Pirate Chai?

Finding the right teacher shouldn't feel like searching through endless profiles.

Pirate Chai is envisioned as a marketplace where students can discover educators based on their:

* Subject and expertise
* Teaching style
* Experience
* Pricing
* Availability
* Learning format

Students can eventually choose between **personalized 1-to-1 sessions** and **structured batch classes**, creating a flexible learning experience around their needs.

## 🧭 Product Direction

The long-term vision is to turn Pirate Chai into a complete learning marketplace.

### Students

Students should be able to:

1. Discover teachers
2. Search by subject or expertise
3. Compare educators
4. View profiles and teaching information
5. Join 1-to-1 sessions
6. Enroll in batch classes
7. Schedule lessons
8. Attend live classes
9. Track their learning

### Educators

Educators should eventually be able to:

1. Create a professional teaching profile
2. List subjects and expertise
3. Set pricing
4. Create 1-to-1 offerings
5. Create batch classes
6. Manage schedules
7. Teach live classes
8. Manage students
9. Track earnings and bookings

## 🚀 Getting Started

### Prerequisites

Make sure you have:

* Node.js
* npm

### Installation

Clone the repository:

```bash
git clone https://github.com/cgrashedflra/Piratechai.git
```

Navigate into the project:

```bash
cd Piratechai
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Then open the local development URL shown in your terminal.

## 🎨 Design Philosophy

Pirate Chai is designed around a simple idea:

> **Learning should feel personal, accessible, and human.**

The interface aims to balance:

* Clarity over complexity
* Strong visual hierarchy
* Fast discovery
* Trust between students and educators
* Minimal friction
* Responsive interaction
* Modern product aesthetics

The frontend prototype prioritizes **realistic product flows over static marketing pages**, allowing the interface to demonstrate how a future production platform could behave.
